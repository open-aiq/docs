Each part of Open AIQ has its own version. A **family** groups the versions
that work together. Open a version for its notes and downloads.

## Making a release

The registry lives in
[`src/data/versions.json`](https://github.com/open-aiq/docs/blob/main/src/data/versions.json)
and is published at [`/versions.json`](https://docs.air-iq.net/versions.json).
Every `make release` checks it first:

- **Patch** (`0.4.1`): goes ahead if its `major.minor` is already registered.
- **Major or minor**: add it to a family, merge, and wait for this site to
  deploy. Until then, the release is refused.
- **Registry unreachable**: the release is refused.

Before 1.0, each minor version is its own family; from 1.0, there's one per
major. New GitHub releases show up on the next deploy. To give one a short
label, add it to the family's `releases` list, like
`{ "version": "0.4.1", "info": "API fix" }`.

New to releasing? Ask in an issue on the component's repository and we'll
walk through it with you.
